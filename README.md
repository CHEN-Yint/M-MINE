M-MINE | AI-powered interactive photo album

A judgment-free private space. Upload photos, and AI friends will automatically comment and like.

Latest Features (v1.2)

- Multi-Theme System: Supports Classic Minimal, Pixel Retro, and Magazine Editorial styles, with customizable theme colors (16 palettes in total).
- Responsive Layout: Bottom navigation on mobile, sidebar with a two-column layout on desktop, adapting seamlessly to all screen sizes.
- Flexible Gallery: Switch between 1, 2, or 3 columns. Supports 3:4 and 1:1 aspect ratios.
- AI Interaction: Built-in AI friend system (customizable name, avatar, personality, and identity). They generate unique comments based on photo categories and keywords, and you can reply to them.
- AI Comment Controls: Add a “secret note to friends” to guide comment topics, or turn off AI comments entirely when publishing.
- Complete Features: Draft box, multi-image upload (up to 9), collections, custom backgrounds, avatars, and data import/export.
- Local Persistence: Uses IndexedDB for large data (works, drafts) with automatic migration from localStorage. Images are compressed via Canvas before saving.
