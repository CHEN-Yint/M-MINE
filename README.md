M-MINE|AI-powered interactive photo album.  
A judgment-free private space. Upload photos, and AI friends will automatically comment and like.

✨ Latest Features (v1.1)
- Multi-Theme System: Supports Classic Minimal, Pixel Retro, and Magazine Editorial styles, with customizable theme colors.
- Responsive Layout: Bottom navigation on mobile, sidebar with a two-column layout on desktop, adapting seamlessly to all screen sizes.
- Flexible Gallery: Switch between 1, 2, or 3 columns. Supports 3:4 and 1:1 aspect ratios.
- AI Interaction: Built-in AI friend system (customizable name, avatar, personality, and identity). They generate unique comments, and you can reply to them.
- Complete Features: Draft box, multi-image upload, collections, custom backgrounds, and avatars.
